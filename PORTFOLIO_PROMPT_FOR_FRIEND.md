## Prompt

```
I'm a DevOps & Platform Engineer and I want to build an iconic, unique, and realistic portfolio website that impresses clients and engineering leaders enough that they directly contact me. 

Build it with:
- Plain HTML/CSS/JS (no frameworks like React/Vue)
- Tailwind CSS CDN for styling
- Vanilla JavaScript for interactivity
- Deploy on GitHub Pages

I am Rajesh Chilukuri, a DevOps & Platform Engineer with 4+ years of experience based in Hyderabad, India (remote-first). My contact: rajeshchilukuri210@gmail.com, LinkedIn: www.linkedin.com/in/rajesh-chilukuri-692506406, GitHub: github.com/Rajesh-210

## Sections to Include:

1. **Hero Section** – Animated typing effect cycling through roles (DevOps Engineer, Platform Architect, Cloud Native Specialist, SRE Practitioner, FinOps Optimizer). Include trust metrics: 99.9% Uptime SLA, 30% Cloud Cost Saved, 15 min MTTR, Daily Deployments.

2. **Animated Background** – HTML5 Canvas with 16 DevOps tool logos (AWS, Kubernetes, Docker, Terraform, Jenkins, ArgoCD, Prometheus, Grafana, Helm, Ansible, GitHub, GitLab, Nginx, Python, Go, Linux) auto-floating continuously WITHOUT mouse interaction. Include constellation connections, mouse repulsion, and rotation.

3. **Dark/Light Theme Toggle** – Animated glass-style backgrounds for both themes. Dark = deep abyss with purple/cyan mesh. Light = frosted white with animated radial gradients. Persist via localStorage and respect system preference.

4. **Interactive Terminal** – macOS-style terminal overlay (open with ` or Ctrl+K). Commands: help, whoami, stack, projects, contact, clear, exit.

5. **FinOps Savings Calculator** – Slider showing monthly/annual cloud savings (30% rate) with spot instance orchestration breakdown.

6. **CI/CD Pipeline Simulator** – 6 stages: Lint → Security Scan → Build & Push → ArgoCD Sync → Canary → Production Live. Live console logs, progress bars, duration timer, results summary.

7. **SRE Incident Post-Mortem** – Timeline (T+0 through T+15), root cause analysis, preventive actions, MTTR metrics.

8. **Case Study Results** – 3 quantified case studies with metrics (cost reduction, MTTR, deployment velocity).

9. **Technical Blog** – 3 engineering articles with read times and email CTAs.

10. **Interactive Architecture Diagram** – Clickable nodes (AWS, VPC, EKS, ArgoCD, Jenkins, Prometheus, Grafana) showing data flow with labels like "Provisions", "Hosts", "Orchestrates", "Deploys", "Builds", "Monitors", "Visualizes".

11. **GitHub Live Stats** – Fetch from GitHub API: public repos, total stars, followers, contributions. Featured repos list.

12. **Contact Section** – Email, Download Résumé (.docx), Calendar booking (Calendly), LinkedIn.

## Design Requirements:
- Glassmorphism (backdrop-filter: blur(24px))
- Gradient borders, gradient text, neon glow effects
- Deep Space Violet palette: #020204 (bg), #bc13fe/#8b5cf6 (purple), #00d4ff/#06b6d4 (cyan), #ff006e/#ec4899 (pink), #10b981 (emerald), #f59e0b (amber)
- IntersectionObserver scroll-reveal animations
- Skillicons.dev for tool logos
- Google Fonts: Outfit, JetBrains Mono, Inter

## Cinematic Package (Optional but recommended):
- Film grain overlay
- Letterbox bars (top/bottom)
- Light leaks (drifting colored glows)
- Parallax depth layers
- Custom animated cursor

## Deliverables:
1. index.html (main portfolio with all sections)
2. dashboard.html (telemetry observability with Chart.js)
3. projects.html (production case studies)
4. share-card.html (WhatsApp/Instagram vertical share card)
5. instagram-reel.html (30s animated vertical video)
6. README.md (project documentation)
7. PORTFOLIO_PROMPT_FOR_FRIEND.md (this prompt file)

## Success Criteria:
- Client-converting content (business outcomes, not just task lists)
- All animations work smoothly
- Mobile responsive
- Fast loading (Tailwind CDN, no heavy frameworks)
- Looks professional and iconic

Make it one of the best DevOps portfolios – if any client looks at it, they should directly contact me.
```
